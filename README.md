# University Management System (UMS)

A **Django-based web application** that simulates a university portal where **students and teachers manage academic activities** such as attendance, CGPA, timetable, and messaging.

---

## Features

**Student Dashboard**

* View attendance percentage
* Check CGPA
* View timetable and courses
* Receive messages from teachers

**Teacher Dashboard**

* Mark student attendance
* Upload CGPA
* Send messages
* Manage timetable

**Authentication**

* Role-based login (Student / Teacher)
* Custom user model with registration numbers

---

## Tech Stack

* **Backend:** Django (Python)
* **Database:** SQLite
* **Frontend:** HTML, CSS
* **ORM:** Django ORM
